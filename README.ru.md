# Header Controls Collapse

Модуль для [Foundry VTT](https://foundryvtt.com/), который сворачивает кнопки в шапке листов актёров и предметов в выпадающее меню ≡. Крестик закрытия всегда остаётся на виду.

## Зачем

Каждый активный модуль добавляет свою кнопку в шапку листа. Когда модулей много, ряд кнопок переполняет заголовок и выдавливает крестик закрытия за край окна. Этот модуль убирает все кнопки (кроме крестика) в компактное меню под кнопкой-гамбургером.

## Возможности

- Все кнопки шапки, кроме крестика, переносятся в выпадающее меню ≡.
- Кнопки сохраняют свои обработчики — работают точно так же, как раньше.
- Подхватываются и кнопки, которые модули дорисовывают асинхронно после открытия листа.
- Настройка **«Минимум кнопок для сворачивания»** (клиентская): меню появляется, только если кнопок не меньше заданного числа.

## Совместимость

- Foundry VTT v12–v13.
- Работает с листами на ApplicationV1 (в том числе все листы pf2e и CoC7).

## Установка

Пока модуль не опубликован в каталоге Foundry, установить его можно вручную:

1. В Foundry откройте **Add-on Modules → Install Module**.
2. В поле **Manifest URL** вставьте:
   ```
   https://github.com/def-gu/header-collapse/releases/latest/download/module.json
   ```
3. Нажмите **Install** и включите модуль в настройках мира.

Либо распакуйте архив релиза в `Data/modules/header-collapse`.
